# amlogic.ru

Сайт ООО «АМ ЛОДЖИК» — https://amlogic.ru

Обычный статический сайт на HTML и CSS: без CMS, базы данных, сборки, JavaScript,
внешних шрифтов, cookie и аналитики. Публикуется через GitHub Pages из корня ветки `main`.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная: о компании, реквизиты, направления деятельности, контакты |
| `privacy.html` | Политика конфиденциальности |
| `404.html` | Страница «не найдено» (пути в ней — от корня сайта) |
| `style.css` | Стили для всех страниц, включая тёмную тему |
| `favicon.svg` | Значок сайта |
| `CNAME` | Домен `amlogic.ru` для GitHub Pages — не удалять |
| `.nojekyll` | Отключает обработку Jekyll: файлы публикуются как есть |
| `robots.txt`, `sitemap.xml` | Для поисковых систем |

## Как внести изменения

Отредактировать файлы (можно прямо в веб-интерфейсе GitHub) и сохранить изменения в `main`.
GitHub Pages опубликует новую версию в течение 1–2 минут.

Если меняется содержание страниц, обновите дату `lastmod` в `sitemap.xml`,
а при изменении политики конфиденциальности — дату редакции в `privacy.html`.
